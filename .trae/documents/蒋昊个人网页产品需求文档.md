## 1. 产品概述
蒋昊的个人自我介绍网页，以科技感黑色主题呈现，展示个人信息、爱好与性格特质。页面两侧设置创意交互按钮，并包含趣味炸弹按钮可将网页"炸毁"。

## 2. 核心功能

### 2.1 页面模块
1. **首页/主页面**：英雄区域（头像/名字）、爱好展示区、性格特质区、创意按钮区、炸弹按钮
2. **无其他页面**，单页应用即可

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 英雄区域 | 大字显示"蒋昊"名字，科技感动效文字，粒子背景 |
| 首页 | 爱好展示 | 三个卡片：游戏、羽毛球、轮滑，悬停展开详情 |
| 首页 | 性格特质 | 网格布局展示12个性格标签，带发光效果 |
| 首页 | 两侧创意按钮 | 左侧和右侧各有小按钮，提供趣味交互（切换主题粒子、显示名言等） |
| 首页 | 炸弹按钮 | 点击后触发全屏爆炸动画，网页元素逐个崩解，最后可点击"复原" |

## 3. 核心流程
用户打开网页 → 查看个人信息与动效 → 探索两侧创意按钮 → 点击炸弹按钮触发爆炸 → 点击复原按钮恢复

## 4. 用户界面设计
### 4.1 设计风格
- 主色调：纯黑 (#000000) 为底色
- 辅助色：霓虹青 (#00f0ff)、霓虹紫 (#b400ff)、霓虹品红 (#ff006e)
- 按钮风格：圆角矩形，发光边框效果
- 字体：科技风无衬线字体搭配未来感展示字体
- 布局：中心主内容，两侧固定悬浮按钮
- 动效：粒子背景、发光脉冲、爆炸崩解动画
- 图标：简约线性图标，配合emoji

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 英雄区域 | 粒子Canvas背景、大字标题、副标题打字机效果、渐变发光 |
| 首页 | 爱好展示 | 三卡片网格、图标+标题+描述、悬停发光边框 |
| 首页 | 性格特质 | 12个标签云、每个标签带随机霓虹色、缓慢浮动动画 |
| 首页 | 两侧按钮 | 左侧3个功能按钮、右侧3个功能按钮、竖排排列、悬停弹出提示 |
| 首页 | 炸弹按钮 | 底部中央、红色警示风格、点击爆炸序列动画 |

### 4.3 响应式设计
桌面优先，平板和移动端自适应，侧边按钮在移动端改为顶部横排
